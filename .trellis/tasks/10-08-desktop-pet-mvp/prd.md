# 桌宠 MVP 完整实现

## Goal

完成 Windows Tauri 2 轻量桌宠：阿拉斯加、德国牧羊犬、暹罗猫、缅因猫四种形象；支持拖动、记住位置、多屏、系统托盘、开机自启、尺寸调节；按健康日饮水目标与间隔/固定时间两种方式提醒；Todo 标题与到期提醒；喝水、喂食、触摸、拖动等动画反馈；预留外部皮肤接口；所有文案走多语言。

## Requirements

- 平台为 Windows 10/11，技术栈固定为 Tauri 2 + Rust + TypeScript/CSS，优先轻量、低常驻开销。
- 内置阿拉斯加、德国牧羊犬、暹罗猫、缅因猫四种卡通毛绒形象；阿拉斯加参考用户提供的真实犬只，不使用夸张眉毛或手绘线稿风。
- 桌宠默认视觉高度约 72px（约 1.5 个桌面图标），允许在 48–144px 范围调节。
- 支持左键拖动、记住位置、多屏幕位置恢复、始终置顶、关闭到托盘、托盘显示/隐藏/退出、可选开机自启。
- 喝水支持两种目标方式：按《中国居民膳食指南（2022）》基线估算（成年男性 1700ml、成年女性 1500ml）和用户自定义目标；健康目标仅作日常提示，可随时覆盖。
- 喝水提醒支持间隔提醒和固定时间提醒，记录当日饮水进度并跨日自动重置。
- Todo 仅包含标题、提醒时间和完成状态；不实现重复、优先级、分类和备注。
- 提供待机、触摸、拖动、喝水、喂食、提醒、完成等动画反馈；MVP 先使用独立静态母版与轻量 CSS 状态动画，资源接口兼容后续序列帧 WebP。
- 外部 `.pet-skin` 皮肤协议预留 manifest 与加载接口，MVP 不提供导入 UI。
- 所有用户可见文案必须通过多语言字典读取，首发简体中文和英文；不使用音效。
- 不设置工作时间、睡眠时间段或免打扰模式。
- 本机 Rust 因第三方安全驱动资源泄漏不用于项目构建；完整 Windows 打包通过 GitHub Actions 验证。

## Acceptance Criteria

- [ ] 四种宠物均能切换并显示独立资源，不再使用 Emoji 占位。
- [ ] 桌宠可拖动、保存位置并在重启后恢复；保存坐标无效时回退到当前可用屏幕范围。
- [ ] 默认约 72px，设置中可在 48–144px 调节；设置面板不随宠物尺寸缩到不可操作。
- [ ] 关闭主窗口后进入托盘，托盘可恢复、隐藏与退出；开机自启开关可持久化。
- [ ] 健康估算与自定义饮水目标都可用；间隔和固定时间提醒都可用；饮水记录每日重置。
- [ ] Todo 可创建、设置提醒时间、完成和删除；到期时触发桌宠提示与系统通知。
- [ ] 喝水、喂食、触摸、拖动和提醒至少有可区分的动画反馈，减少动画开关生效。
- [ ] 中英文界面无新增硬编码用户文案。
- [ ] `npm run build` 通过，GitHub Actions Windows 打包成功并产出 artifact。

## Notes

- 饮水基线来源：《中国居民膳食指南（2022）》在温和气候、低身体活动水平下的成人建议；疾病、妊娠、高温或高强度运动等情况应遵医嘱或自行调整。
- 正式逐帧动画资产可独立迭代，不阻塞 MVP 状态机和交互完成。
