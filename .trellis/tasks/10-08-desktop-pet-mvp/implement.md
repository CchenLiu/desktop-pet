# 实施计划

1. 初始化 Trellis 任务并固化 PRD、设计和验收标准。
2. 生成四种宠物独立母版，接入资源注册表和动作状态机，替换 Emoji。
3. 重构界面为“小宠物常态 + 固定尺寸功能浮层”，完善尺寸、拖动与交互动画。
4. 升级饮水状态：指南/自定义目标、可靠的间隔/固定提醒、跨日重置。
5. 升级 Todo：提醒时间、完成、删除、到期通知。
6. 完善位置恢复、多屏校正、托盘、自启和多语言字符串。
7. 更新 README/皮肤协议文档，运行 `npm run build`。
8. 使用中文提交信息提交并推送，等待 GitHub Actions Windows 打包成功。

## 提交边界

- Trellis/规格单独提交。
- 角色资源与动画框架单独提交。
- 饮水/Todo/窗口行为按可独立验证的功能提交。
- 构建修复不与功能提交混合。
